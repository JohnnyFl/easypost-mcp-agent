# Evals: чи обирає агент правильний тариф

Набір кейсів: `agent/evals/cases.json` (10 кейсів: 8 навчальних і 2 held-out). Кожен кейс прогоняється 3 рази на фейковому EasyPost,
перевіряється точний збіг куплено `rate_id` з очікуваним. Запуск: `cd agent && uv run python -m evals.run`.
Модель: `claude-haiku-5-5`.

## Правило правильного вибору
1. Відкинь тарифи з `delivery_days > max_days`. Якщо є обмеження за днями, відкинь і тарифи з невідомими днями (`null`).
2. З тих, що лишились, обери найдешевший; при рівних цінах швидший.
3. Якщо нічого не підходить, агент каже про це і нічого не купує.
4. Без схвалення купівлі немає ніколи.
5. Якщо користувач просить інше («найшвидший до $10»), правильне те, що він просив.

Крайові випадки: рівні ціни; невідомі дні при дедлайні; усі дні невідомі; найдешевший є найповільнішим; нічого не вкладається в дедлайн; інша ціль.
